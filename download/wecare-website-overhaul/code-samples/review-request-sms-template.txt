Available placeholders (HubSpot personalisation tokens):
  {{ contact.firstname }}                  - Customer's first name
  {{ contact.lastname }}                   - Customer's last name
  {{ custom.appliance }}                   - Appliance serviced
  {{ custom.technician_name }}              - Technician who did the repair
  {{ custom.service_date }}                - Date of service (e.g. "yesterday")
  {{ custom.review_link }}                  - GBP review link (short URL)
  {{ contact.phone }}                      - Customer's phone (for reference only)

HUBSPOT WORKFLOW CONFIGURATION (recommended)
────────────────────────────────────────────────────────────────────────
1. Trigger: Contact stage changes to "Service Completed" in FixCare Deals pipeline.
2. Action 1 (T+24h): Send SMS Template 1 (primary review request)
3. Action 2 (T+5d): Check if review left (manual flag set by ops after checking GBP)
                 - if NO review left → send SMS Template 2 (follow-up)
4. Action 3 (T+3d): Send Email Template 3 to all contacts with email on file (regardless of SMS)
5. Action 4 (continuous): Monitor GBP for new reviews; if a 1-3★ review appears,
                 trigger Template 4 alert to ops team via Slack/email.
6. Action 5 (T+2d after resolution): Send Template 5 if customer confirms satisfaction after the follow-up call.

Target metrics:
  - 4-6 new Google reviews per month (year 1)
  - 35-45% review request → review completion rate
  - Average rating maintained above 4.7 stars
  - 100% of negative reviews responded to within 24 hours
